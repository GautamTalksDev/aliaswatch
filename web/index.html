"Did it get nerfed?"

It is one of the most repeated questions in AI. Every week, someone is certain their model got worse overnight. Sometimes they are right. Sometimes it is Tuesday.

The problem is not that models change. Providers reroute, re-quantise, adjust system prompts, and swap weights behind a stable name, and that is their right. The problem is that there is no neutral record. Everyone has a feeling. Nobody has a number.

"Refusing stuff it did fine last week."
"Same prompt, totally different output. Nothing changed on my end."
"Is it just me or is it dumber today?"

Composite paraphrases, not attributed quotations.

    How it works

    01

    Ask the same questions

    166 prompts in six families - facts, format, constraints, refusals, tool calls, verbosity - sealed with a hash so they can never be quietly edited to change the result.

    02

    Grade by machine

    Exact match, regex, schema, numeric tolerance. Never a language model judging another language model. A grader that drifts would make the whole record meaningless.

    03

    Measure the noise first

    Temperature 0 is not deterministic. Each model gets its own per-family noise floor from its own history, and only movement beyond that floor counts - corrected for six chances a day to be wrong.

    04

    Sign it and publish it

    Every day is hashed, chained to the day before, and signed. Rewriting history breaks every link after it. You can verify the whole chain in your browser, or offline with no dependencies.

    What it will never tell you

    AliasWatch measures the alias - the name you send your requests to - not the weights behind it. A routing change, a hidden system-prompt change, a quantisation change and a weight swap all look identical from the outside.

    So it reports that the thing you call by that name behaves differently. It never says why, never says a provider "nerfed" anything, and never characterises a model as worse. That restraint is enforced in code, and it is the reason the record can be cited.

    Why you can trust it

    • Raw model outputs archived for every day, forever
    • Graders and battery public; re-run them and get the same numbers
    • False-alarm rate measured by simulation before the first flag was ever published
    • Ed25519-signed, hash-chained daily log
    • Gaps shown as gaps - an incomplete day is never published as data
    • No accounts, no analytics, no cookies, no external requests
